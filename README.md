# DoseMate - Smart MedCare

## 📌 Project Description
DoseMate is an interactive, minimalist healthcare web application designed to help patients manage their medication schedules effortlessly. Built with a soothing light cream theme, it allows users to quickly log their prescriptions and track their daily doses.

## 🚀 How to Run and Test
1. Clone this repository to your local machine.
2. Open the project folder.
3. Simply double-click on the `index.html` file to open it in any modern web browser (Chrome, Edge, Safari).
4. Enter a medicine name and time in the input fields and click "Add Reminder" to test the interactivity.

## ✨ Features and Functionality
* **Add Medication:** Users can input the name and specific time for their medicine.
* **Interactive UI:** Smooth animations when a new reminder is added.
* **Task Completion:** A single-click "Done" button to clear taken medications from the list.
* **Minimalist Aesthetic:** A distraction-free, light cream interface optimized for accessibility.
